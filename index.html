About This Project

The Urban Flood Nowcasting System demonstrates how combining real-time rainfall intensity data with drainage network capacity can produce actionable flood-risk information for every urban zone. The core equation is simple:

Flood Risk = Rainfall Factor + Drainage Load Factor + Zone Vulnerability

All values shown are simulated prototype data. This prototype was built for demonstration purposes. In a real deployment, live sensor data and GIS layers would replace the simulated inputs.
