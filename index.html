ℹ️ About This System

The Urban Flood Nowcasting System by Team TECHX is a prototype demonstrating how real-time rainfall intensity combined with drainage capacity data can produce zone-level flood risk estimates for urban areas. This prototype uses simulated data only and does not connect to any live data sources.

Risk Formula (simplified):
Flood Risk = Rainfall Factor × 0.45 + Drainage Load Factor × 0.35 + Zone Vulnerability × 0.20
